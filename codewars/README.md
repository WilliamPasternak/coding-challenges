# Codewars

A collection of solutions to programming challenges from [Codewars](https://www.codewars.com/), written primarily in JavaScript.

## Organization

Solutions are organized by year, with historical solutions maintained by Kyu difficulty.

### Historical Challenges (Pre-2026)

Challenges completed before 2026 are organized by Kyu rank.

Codewars uses a reverse difficulty scale: **8 Kyu is the easiest rank, while 1 Kyu is the hardest.** Lower Kyu numbers indicate greater difficulty.

- 8 Kyu – Beginner
- 7 Kyu – Novice
- 6 Kyu – Competent
- 5 Kyu – Proficient
- 4 Kyu – Advanced
- 3 Kyu – Very Advanced
- 2 Kyu – Highly Advanced
- 1 Kyu – Expert

### Daily Challenges (2026–Present)

Starting in 2026, daily challenges are maintained in a single file for each year, with solutions added as challenges are completed.

## Language

- JavaScript

## Purpose

Practice programming fundamentals, strengthen problem-solving skills, and develop familiarity with algorithms, data structures, and different approaches to solving programming challenges.
